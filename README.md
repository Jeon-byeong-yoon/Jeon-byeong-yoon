## About

문제를 정확히 정의하고, 데이터를 꼼꼼히 정리하며, AI 모델과 서비스 구조가 목적에 맞게 작동하도록 만드는 과정에 집중합니다.

프로젝트를 진행하며 **좋은 결과는 모델 구조뿐 아니라 데이터 품질, 전처리 방식, 변수 구조, 학습 흐름을 체계적으로 관리하는 과정에서 나온다**는 점을 배웠습니다.
